# Chapter 1 – Project Presentation

## Project Overview

Movie Melody is a multimedia website developed as part of the Internet Technologies course.

The purpose of the website is to help users discover songs that match the atmosphere and genre of popular movies. Users can browse movie recommendations, explore suggested songs, view subscription plans, and access help information through a dedicated FAQ page.

The website was created using HTML5, CSS3, JavaScript, XML, and XSD. All pages are static and connected through a navigation menu.

## Target Audience

Movie Melody is intended for movie and music enthusiasts who want to discover songs that complement their favorite films and genres.

## Project Features

The website includes:

* Home page introducing the project.
* Suggested Songs page with movie recommendations and matching songs.
* Pricing page presenting subscription plans.
* Help page with Frequently Asked Questions and a contact form.
* XML document containing movie and song information.
* XSD schema used to validate the XML document.
