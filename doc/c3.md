C3: Product
Product Description
Movie Melody is a site dedicated to making movie recommendations. Movie Melody helps find appropriate music to go with certain scenes within a film. The website features a list of popular films together with suitable songs. There are also timestamps to assist in finding the right scene. This service is accessible through an easy-to-use interface.
3.1 Installation
GitHub Repository Setup

The project source code is hosted on GitHub in the repository:

https://github.com/inf25tig01/movie_melody_project

To install the project locally:

Install Git.
Clone the repository:
git clone https://github.com/inf25tig01/movie_melody_project.git
Open the project folder in Visual Studio Code.
Open the index.html file in a browser or use the Live Server extension.
Netlify Deployment

The website is deployed using Netlify.

Deployment steps:

Create a free Netlify account.
Connect the GitHub account.
Import the GitHub repository.
Select the main branch.
Deploy the site.

Netlify automatically updates the website whenever new changes are pushed to GitHub.

3.2 Usage

Movie Melody can be used without creating an account.
Website URL: https://inf25tig01.netlify.app

Users can:

Browse movie recommendations.
View suggested songs for each movie.
Access song timestamps.
Explore pricing plans.
Download movie information in XML format.
Read the help and FAQ section.
Limitations
Song recommendations are predefined.
Users cannot upload their own movies.
No authentication system is currently implemented.
Streaming movies directly from the website is not supported.
