# C3: Product

## Product Description

Movie Melody is a website dedicated to making movie recommendations more immersive through music.

The platform helps users discover suitable songs for specific movie scenes and provides timestamps indicating when the song should begin. Users can browse a collection of popular films, view suggested songs, and explore pricing plans through a simple and visually appealing interface.

**Website URL:** https://inf25tig01.netlify.app

**GitHub Repository:** https://github.com/inf25tig01/movie_melody_project

---

## 3.1 Installation

### GitHub Repository Setup

The project source code is hosted on GitHub:

https://github.com/inf25tig01/movie_melody_project

### Local Installation

1. Install Git.
2. Clone the repository:

```bash
git clone https://github.com/inf25tig01/movie_melody_project.git
```

3. Open the project folder in Visual Studio Code.
4. Run the website using Live Server or open `index.html` directly in a browser.

### Netlify Deployment

The website is deployed through Netlify.

Deployment steps:

1. Create a free Netlify account.
2. Connect the GitHub account.
3. Import the repository.
4. Select the `main` branch.
5. Deploy the website.

Netlify automatically redeploys the website whenever changes are pushed to GitHub.

## 3.2 Usage

Movie Melody can be used without creating an account.

### Features

- Browse movie recommendations
- View song recommendations
- Access song timestamps
- Explore pricing plans
- Download movie information in XML format
- Access the Help and FAQ section

### Limitations

- Song recommendations are predefined.
- Users cannot upload their own movies.
- No user authentication is required.
- Movies cannot be streamed directly from the website.

## 3.5 HTML5 and CSS3 Validation

### HTML Validation

The HTML pages were validated using the W3C Markup Validation Service:

https://validator.w3.org/

Validated pages:

- index.html
- songs.html
- pricing.html
- help.html

During development, validation errors related to structure and formatting were corrected. The final version of the website was tested to ensure compliance with HTML5 standards.

### CSS Validation

The stylesheet was validated using the W3C CSS Validator:

https://jigsaw.w3.org/css-validator/

Validated file:

- css/style.css

The stylesheet was checked for syntax errors and invalid properties. Corrections were made where necessary to ensure compatibility and proper rendering.

### XML Validation

The XML file was validated against the XML Schema Definition (XSD).

Files used:

- xml/movies.xml
- xml/movies.xsd

Validation process:

1. The XML document was checked for well-formedness.
2. Special characters were corrected using XML entities.
3. The XML structure was compared against the XSD schema.
4. Validation errors were corrected until the XML document successfully matched the schema definition.
